# C → Rust idioms

One row per settled idiom. Add a row when the idiom is decided, in the same commit as its first use.
Columns: what OpenBSD C does | what we write | why.

| C (OpenBSD) | Rust (here) | Why |
|---|---|---|
| `int f(...)` returning `0` or an errno | `fn f(...) -> Result<T, Errno>` | the type carries the contract; `?` replaces `goto out` |
| errno values (`EINVAL`, `ERESTART = -1`, `EJUSTRETURN = -2`) | `#[repr(i32)] enum Errno` in `sys/sys/errno.rs`, same names and values | ABI-visible numbers; names grep across both trees |
| `LIST_HEAD(name, type)` plus the `field` argument of every `LIST_*` macro (`queue.h`; same for SLIST, SIMPLEQ, XSIMPLEQ, TAILQ, STAILQ) | `ListHead<A>` with `A` a zero-sized `Adapter` from `queue_adapter!(A: Elem, field => ListEntry<Elem>)`; the element embeds `ListEntry<Elem>`; readers are safe, mutators `unsafe` with the C precondition as contract | the field is fixed once and type-checked; O(1) unlink, one element in several lists, no allocation, as in C |
| `SPLAY_GENERATE`, `RB_GENERATE`, `RBT_GENERATE[_AUGMENT](name, type, field, cmp[, aug])` (`tree.h`) | `tree_adapter!(A: Elem, field => RbtEntry, cmp[, augment = aug])` with `cmp` returning `Ordering`; heads `SplayHead<A>`, `RbHead<A>`, `RbtHead<A>`; `RB_*` and `RBT_*` share the `kern/subr_tree.rs` algorithm | the comparator and the hook belong to the adapter, as `struct rb_type` already bundles them in C; one red-black implementation instead of a macro copy |
| `int cmp(a, b)` returning negative, zero or positive | `fn cmp(a: &T, b: &T) -> Ordering` | the type says the three outcomes; `match` checks them all |
| `s = splhigh(); ... splx(s);` | `let _s = IplGuard::raise(Ipl::High);` | drop restores; a forgotten `splx` is impossible |
| `mtx_enter(&m); ... mtx_leave(&m);` | `let g = m.lock();` on the ported `Mutex<T>` (`kern_lock.c`, IPL-aware) | data lives inside the lock; the guard proves it is held |
| `KASSERT(x)` / `KDASSERT(x)` | `kassert!(x)` / `kdassert!(x)` behind features `diagnostic` / `debug` | same text: `kernel diagnostic assertion "x" failed: file "f", line n` |
| `panic("fmt", ...)` | `panic!("fmt", ...)` routed to `kern::subr_prf::panic` | identical message; `#[allow(clippy::panic)]` with a reason at each site |
| `printf(9)`, `log(9)`, `%b` | `kprintf!`, `kprintln!`, `log!(LOG_x, ...)`; a `Bitmask(value, "\20\1FLAG...")` `Display` helper for `%b` | Rust format strings; `%b` has no counterpart so it is a wrapper |
| `#ifdef OPTION` | `#[cfg(feature = "option")]` | one knob per `option(4)`, visible in `Cargo.toml` |
| `struct proc *p` passed down (borrowed) | `&Proc` | no ownership transfer |
| `struct proc *` in lists or long-lived | `Cell<*const Proc>` inside the list entries, `&Proc` at the API; `Arc<Process>` after M3 for `refcnt(9)` | the link is a raw pointer under the list's lock; every borrow is explicit |
| fields mutated under a lock through a shared pointer | `UnsafeCell<T>` field with doc `/// Protected by: <lock>` | states the invariant the C only implies |
| `vaddr_t`, `paddr_t`, `vsize_t`, `psize_t` | `Vaddr(usize)`, `Paddr(usize)`, `Vsize(usize)`, `Psize(usize)` newtypes | the compiler stops VA/PA mix-ups |
| `#define FOO_X 0x1` flag groups | `bitflags! { struct FooFlags: u32 { const X = 0x1; } }` | typed, same names, same bits |
| `volatile` MMIO | `read_volatile` / `write_volatile` behind `bus_space`-shaped accessors | no plain dereferences of device memory |
| linker symbols (`end`, `etext`) | `unsafe extern "C" { static __kernel_end: u8; }` + `addr_of!` | address-only symbols, never read as values |
| `goto out` cleanup | `?`, RAII guards, labelled blocks | same control flow, enforced release |
| `.S` files | real `.S` file + `global_asm!(include_str!("x.S"))` | diffable against OpenBSD's |
| `static` globals | `static X: Mutex<T>`, atomics, or `StaticCell<T>` (documented init-once) | `static mut` is forbidden |
| `caddr_t`, `void *` buffers | `&[u8]` / `&mut [u8]`; `NonNull<u8>` only at ABI edges | the length travels with the pointer |
| C strings (`char *`, not UTF-8) | `&[u8]` NUL-terminated or `&CStr`; never `&str` in kernel ABI | kernel strings are bytes |
| `size_t` / `ssize_t` | `usize` / `isize` | same width, same meaning |
| `<machine/param.h>`, `<machine/_types.h>` constants (`PAGE_SIZE`, `KERNBASE`, `_ALIGNBYTES`) | associated consts of `machine::MachineParam`, defined per arch in `arch/<arch>/include/{param,_types}.rs`, re-exported by `sys::param` | generic code never names an arch; the compiler proves every arch defines the whole set |
| `typedef __int32_t pid_t;` and the other scalar typedefs of `<sys/types.h>` | `pub type Pid = i32;` in `sys/sys/types.rs`: CamelCase, no `_t` | the `_t` is C namespace hygiene; the alias keeps the width and the doc comment names the C type |
| `u_int`, `u_long`, `u_int32_t`, `quad_t`, `int8_t`, ... | `u32`, `u64`, `u32`, `i64`, `i8`, ...: no alias | the primitive already states the width; both archs are LP64 |
| `#define NAME 42` in a header | `pub const NAME: usize = 42;` in that header's module, with the narrowest honest type (`usize` for sizes and counts, `i32` where C passes an `int`) | names stay grep-able; the type documents the use |
| function-like macros in capitals: `ALIGN(p)`, `MAXCOMLEN`-style arithmetic, `howmany(x, y)`, `ctod(x)` | snake-case `const fn` in the same module: `align`, `howmany`, `ctod` | untyped macros buy nothing in Rust; lowercase is the only change |
| `MIN`/`MAX`, `offsetof`, `nitems`, `SET`/`CLR`/`ISSET` | `core::cmp::{min, max}`, `core::mem::offset_of!`, `.len()`, `|=` / `&= !` / `&` | already in core |
| `const char *s` string argument | `&[u8]` ending at the first NUL or at `s.len()`, whichever comes first | no read past the slice is possible; a NUL-free slice is still a string |
| `int f(...)` that is really a boolean (`timingsafe_bcmp` returns 0 or 1) | `-> bool`, the doc stating `true` where C returns nonzero | `if f(..)` reads the same in both languages |
| constant tables (`crc32c_lookup[]`) | `const TABLE: [u32; 256] = build_table();` computed by a `const fn` from the defining polynomial; `just test-ref` compares every entry with the C header | the data is reproduced, not copied; the reference test keeps it honest |
| `static __inline` wrappers around one instruction (`inb`, `outb`, `intr_disable`, `disable_irq_daif`) | `#[inline] pub fn` (or `pub unsafe fn` when the instruction has a precondition) with `core::arch::asm!`, `options(nomem, nostack, preserves_flags)` only where each is true | the compiler inlines as GCC did; the options let it schedule around the instruction honestly |
| `int c` characters in the console and printf paths (`cnputc(int)`, `kputchar(int, ...)`, `cn_putc(dev_t, int)`) | `i32`, with `i32::from(b'x')` at the call sites | the C contract (`-1`, `0177`, a NUL that is skipped) is an `int`'s; a `u8` would hide the sentinel values |
| `printf("%s", cstr)` of a NUL-terminated byte string | `Str(&bytes)` (`kern::subr_prf::Str`), a `Display` adaptor that stops at the first NUL | kernel strings are bytes, Rust format strings want `Display` |
| a table of function pointers (`struct consdev`, `struct bus_space`, `arm_clock_func`) | a `struct` of `fn` pointers (`Option<fn>` where the C allows NULL), a `static` instance per device | the C design is a vtable; Rust spells it the same way, with no trait object or allocation |
| calling into a subsystem that is not ported yet | `unported!("uvm_map")` (`sys/kern/unported.rs`): prints once per site, yields `Errno::ENOSYS` | the gap is visible on the serial console and in the message buffer, and propagates as an error where the C returned one |
| `bus_space_tag_t` / `bus_space_handle_t` | the arch's `Tag`/`Handle` associated types of `machine::BusSpace`, aliased as `BusSpaceTag`/`BusSpaceHandle`; `bus_space_map` is `unsafe` (the caller vouches for the device), reads and writes through a handle are safe | a handle only comes from a map; the one `unsafe` is where the firmware's word is taken |
| `__builtin_frame_address(0)` | `Machine::frame_address()`, an `#[inline(always)]` `asm!` reading `rbp`/`x29` | no stable intrinsic; inlining keeps it the caller's frame |
| `paddr_t` holding a page frame number (`atop()` results, `vm_physseg.start`, `uvm_pmemrange.low`) | `usize`; byte addresses stay `Paddr` | the newtype keeps bytes and frames apart; frame arithmetic is plain integer arithmetic |
| `pg + n`, `pg - n` over a `vm_page` array (`uvm_pmemrange.c`) | `VmPage::add(n)` / `sub(n)`, `unsafe` with the one-array invariant; `ptr_add(n)` returns a pointer for comparisons only | the C relies on the pages of one segment being one array; the `unsafe` names that invariant, and a comparison may point one past the end |
| `KASSERT(e)` / `KDASSERT(e)` without `DIAGNOSTIC` / `DEBUG` | `kassert!` / `kdassert!` keep `e` inside a closure that is never called | nothing is evaluated, as in C, but `e` still type-checks and the names it uses do not become "unused" when the feature is off |
| `struct uvmexp` counters bumped from everywhere (`uvmexp.free++`) | one `static UVMEXP: Uvmexp` whose fields are `AtomicI32`, `Relaxed` | the C updates them racily under assorted locks; atomics are the honest spelling and need no `static mut` |
| `int`/`long` struct fields mutated through a shared pointer under a lock (`pmr->nsegs++`, `pg->fpgsz`) | `Cell<T>` for `Copy` fields, the lock named in the doc comment; `UnsafeCell` only for non-`Copy` data | a `&self` API like the C's; `Cell` never hands out references, so the lock is the only invariant |
| `static struct vm_physseg vm_physmem[VM_PHYSSEG_MAX]; int vm_nphysseg;` | `StaticCell<[VmPhysseg; N]>` written only before `uvm.page_init_done` through `vm_physmem_mut()` (unsafe), read through `vm_physmem()` | boot-time tables are written once on one CPU; the one `unsafe` states when |
| `struct pool_item` / `struct kmem_freelist` overlaid on free memory | `#[repr(C)]` structs of `Cell`s and a queue entry, reached with `&*(ptr as *const T)` | any bit pattern is a valid value of such a struct, so the free block's old contents are harmless; the `Cell`s keep the API `&self` |
| `union pool_lock { struct mutex; struct rwlock; }` | `PoolLock`, a `Cell<bool>` behind the `pool_lock_ops` table | the lock arrives with M5; the flag already catches recursion and unlocked access through `pl_assert_*` |
| `void *` returned by an allocator (`malloc`, `pool_get`, `km_alloc`) | `Option<NonNull<u8>>` | NULL is `None`; the caller casts to its type at the one place it knows it |
| a `GlobalAlloc` for `alloc::*` | `kern/rust_alloc.rs` over `malloc(9)`/`free(9)` with `M_TEMP`, the size raised to the alignment | the kernel allocator stays OpenBSD's; Rust's containers are a client of it, not a second allocator |
| whole-file assembly with `assym.h` symbols (`vector.S`, `locore.S`, `exception.S`: `TF_RIP`, `GSEL(...)`, `T_PAGEFLT`) | the `.S` file next to the module, included by `global_asm!(include_str!("x.S"), NAME = const offset_of!(..), ...)`; the file writes `{NAME}` where C wrote the macro | the assembly stays diffable against OpenBSD's, and the offsets come from the Rust struct, so `genassym` has nothing to generate |
| C functions called from assembly (`kerntrap`, `do_el1h_sync`, `arm_cpu_irq`) | `#[unsafe(no_mangle)] pub extern "C" fn name(frame: &mut Trapframe)` | the symbol name is the C's, the ABI is the platform's, and a `&mut` to a `#[repr(C)]` frame is FFI-safe |
| bit-field descriptors (`struct gate_descriptor`, `mem_segment_descriptor`, `sys_segment_descriptor`) filled field by field (`setgate`, `set_mem_segment`) | `#[repr(C)]` structs of `u64` words with a `const fn pack(...)` that places every field; the `set*` functions call `pack` | Rust has no bit-fields; the packer is one place where the layout is written down and unit-tested against known descriptors |
| `READ_SPECIALREG(reg)` / `WRITE_SPECIALREG(reg, val)` | `read_specialreg!("esr_el1")` / `write_specialreg!("mdscr_el1", v)`, `macro_rules!` taking the register name as a string literal | `asm!` needs the register name at compile time, as the C's `__STRING(reg)` does |
| `curcpu()` (`%gs:ci_self`, `mrs tpidr_el1`) and `struct cpu_info` fields the CPU mutates | `fn curcpu() -> &'static CpuInfo` with `Cell`/`AtomicU32` fields; `ci_panicbuf` is an `UnsafeCell` | the per-CPU struct is shared by every path on that CPU; `Cell` keeps the API `&self`, the atomics are the fields other CPUs read |
| `db_regs_t ddb_regs` (the trap frame the debugger works on) | `static DDB_REGS: StaticCell<Trapframe>`, written by `db_ktrap` on the CPU in the debugger, read by `db_trace`/`db_trap` while `db_active` | the C's global is written once per debugger entry on one CPU; the `unsafe` accesses name that window |
| a C global the assembly reads by name (`i8259_imen`, `intr_shared_edge`, `uvmexp`, `local_apic`) | a Rust `static` with `#[unsafe(no_mangle)]` or `#[unsafe(export_name = "...")]`, atomic or `UnsafeCell` inside | the `.S` file keeps the C's symbol and the Rust side keeps a safe type; both name one object |
| `struct mutex` with `mtx_enter`/`mtx_leave` under a static `MUTEX_INITIALIZER` | `static M: Mutex = Mutex::new(IPL_X)`, `mtx_enter(&M)`/`mtx_leave(&M)` (`kern/kern_lock.rs`); the owner is `Machine::curcpu_ptr()` | the C API is `&self`; the owner field compares CPUs, so an opaque pointer is enough for every arch |
| `void *` handle returned by `*_establish` and taken back by `*_disestablish`/`*_schedule` | `Option<NonNull<T>>` out, `NonNull<T>` in, with `disestablish` `unsafe` (it frees) | the caller cannot forge a handle; the one `unsafe` is where the memory goes away |
| `.macro`-style C macros that generate assembly per instance (`INTRSTUB(name, num, ...)`, `i8259_asm_mask(num)`) | GAS `.macro` blocks in the `.S` file, invoked once per instance; the C's `name##num` is `\name\()\num` | the file stays one assembly source, diffable with OpenBSD's, with no preprocessor |
| a device tree node (`void *` into the blob) and an `OF_*` handle (`int` offset) | `FdtNode = *const u32` (null is `NULL`) and `i32` handles, both kept; property values come back as `&'static [u8]` slices into the blob, `None` for the C's `-1` | the blob lives forever and is only read, so slices carry the length the C returned separately |
| `char *name` arguments compared with `strcmp` (`fdt_node_property(node, "reg", ...)`) | `&[u8]` without the NUL (`b"reg"`), compared with the blob's NUL-terminated strings | byte-string literals are the kernel's strings (`Str`), and no NUL has to be appended at every call |
| `struct cpu_info` members that generic code reads (`curcpu()->ci_queue`, `ci_schedstate`, `ci_randseed`) and the `CLKF_*` macros over `struct clockframe` | associated types `Cpu::CpuInfo`/`Cpu::ClockFrame` with accessor methods (`Machine::ci_queue(ci)`, `Machine::clkf_usermode(frame)`), re-exported as `machine::cpu::CpuInfo` | each arch defines its own `cpu_info`, as in C; generic code names the member through the contract instead of the arch |
| `timercmp(a, b, <)`, `timespeccmp`, `bintimecmp` | the derived `Ord` on `Timeval`/`Timespec`/`Bintime` (seconds first, then the fraction): `a < b` | the lexicographic derive is exactly the macro's two-step comparison |
| `membar_producer()` / `membar_consumer()` around a generation-checked read (`timehands`, `pc_lock`, `cq_gen`) | `fence(Ordering::Release)` / `fence(Ordering::Acquire)` with the generation in an atomic and the payload in `Cell`s | the C's barriers map to fences; the atomic generation is the only word two sides race on |
| a `.c` global of function-pointer type that autoconfiguration retargets (`initclock_func`, `startclock_func`) | `static F: StaticCell<fn()>` with a setter (`set_initclock_func`) | a write-once-at-boot pointer, like the other `StaticCell` uses; the setter names the one writer |
| a per-arch struct embedded in a generic one (`struct mdproc` in `struct proc`, `struct pcb` in `struct user`) whose instance is a `static` (`proc0`, `proc0paddr`) | associated types on the `machine::proc::MachineProc` trait plus associated **constants** as initialisers (`const PCB_INIT: Self::Pcb`); `Proc::new()` is a `const fn` that uses them | a trait cannot have `const fn`s, but an associated const is usable in a `static` initialiser, so `proc0` stays a `static` as in C |
| a C global list head (`allproc`, `kthread_q`) | a `static` newtype around the head (`ProcListHead(ListHead<..>)`) with `unsafe impl Sync` stating the lock | the heads hold `Cell`s; the wrapper is where the locking claim is written down |
| a C identifier that is a Rust keyword (`yield()`, a field `gen`) | a raw identifier for a function or type the C names (`r#yield`); a local variable is just renamed (`generation`) | the OpenBSD name survives for anything a caller spells; a local is nobody's API |
| a function pointer handed to assembly to `call` later (`sf_r12 = func` in `cpu_fork`, `blr x19` in `proc_trampoline`) | the `fn(*mut c_void)` is stored as a `*const ()` in the switch frame and the assembly passes it, with its argument, to a Rust `unsafe extern "C" fn proc_trampoline_run` that transmutes it back and calls it | Rust `fn` pointers have no C calling convention, so the assembly never calls one directly; the one transmute is the inverse of the one cast |
| an MD `int` that MI code declares `extern` and every `machdep.c` defines identically (`cold`, `safepri`, `physmem`) | one `static` in `sys/sys/systm.rs` (`COLD`, `SAFEPRI`, `PHYSMEM`), which the archs write | nothing per arch differs; a trait method would be three copies of the same line |
| `proc0paddr`: the u-area `locore` reserves in `.bss` for proc0 (`USPACE` bytes, the `struct user` at the bottom) | `static PROC0_UAREA: Uarea` per arch, `Uarea` being `#[repr(C, align(4096))] { u: User, _stack: [u8; USPACE - size_of::<User>()] }` in `sys/sys/user.rs` | `cpu_fork` copies the parent's trap frame from the top of its u-area, so proc0's must be a real `USPACE` block even though it boots on the loader's stack |
| `syscalls.master` run through `makesyscalls.sh` into `syscall.h`, `syscallargs.h`, `init_sysent.c`, `syscalls.c` | `cargo xtask gen-syscalls` (`tools/xtask/src/syscalls.rs`) writes `sys/sys/syscall.rs`, `syscallargs.rs`, `kern/init_sysent.rs`, `kern/syscalls.rs`; `--check` runs in `just ci` | the generated files are committed like the C's; the table points unported syscalls at `sys_nosys`, found by scanning for `pub fn sys_*` |
| `syscallarg(x)` (a `register_t`-wide union per argument) and `SCARG(uap, k)` | `Syscallarg<T>` union with `.get()`, the `sys_*_args` structs as `#[repr(C)]` with one slot per argument, `sysargs::<T>(v)` for the cast | the arguments are the trap frame's registers in a row, so the struct must be register-wide per field; `get` reads the low bytes as the C's `le.datum` |
| `int sys_foo(struct proc *, void *, register_t *)` | `fn sys_foo(p: &Proc, v: &SysArgs, retval: &mut [Register; 2]) -> Result<(), Errno>` (`SyCall` in `sys/systm.rs`; `SysArgs` is the six argument registers, `sysargs::<SysFooArgs>(v)` the safe `SCARG` view) | the errno and `ERESTART`/`EJUSTRETURN` go through `Errno`; the `void *` becomes a reference to the register block the MD entry already has, so no syscall needs `unsafe` to read its arguments |
| the user/kernel copy routines in assembly with `pcb_onfault` (`copyin`, `copyout`, `copyinstr`, `copyoutstr`, `kcopy`) | the `.S` stays assembly (global_asm!), the Rust entry points take the kernel side as a slice (`copyin(uaddr: usize, kbuf: &mut [u8])`) and only `kcopy` is `unsafe` | the only thing that can be wrong is the user address, which the assembly checks and whose fault it catches; the slice carries the length the C passed separately |
| an ELF header read out of a file with `vn_rdwr` into a `malloc`ed `Elf_Ehdr`/`Elf_Phdr` | `read_image!(ElfEhdr, image, off)`: a bounds-checked `ptr::read_unaligned` out of the image slice, `None` when short (`elf_read_from` returns `ENOEXEC`) | the structures are `#[repr(C)]` integers, valid for every bit pattern, so the one `unsafe` is the unaligned read; the slice bounds replace the C's `resid` check |
| `caddr_t`/`vaddr_t` fields that hold user addresses (`vm_taddr`, `ps_strings`, `ev_addr`) | `usize` in the structures, `Vaddr` only at the `machine` contract (`pmap_enter`, `setregs`) | a user address is a number the kernel never dereferences; the newtype marks the places where an architecture does |
| `sys_execve` for the one caller that has the executable in memory (`start_init` with a boot module) | `exec_image(p, name, image)`: the C body from `check_exec` on, over an `ExecPackage` whose `ep_hdr` is the whole image; `Err(EJUSTRETURN)` is success, as the syscall's | the name is this port's (the C has no such function) and goes away when `sys_execve` and `namei` exist; the vmcmds and the ELF loader are the C's, with an offset into the image where they had a vnode |
| `struct rwlock`'s `volatile unsigned long rwl_owner` holding a `struct proc *` or a reader count plus flag bits | `AtomicUsize`: the writer's `*const Proc` as an integer with `RWLOCK_WRLOCK` or'ed in (`rw_self`), the readers shifted by `RWLOCK_READER_SHIFT`; `rw_enter` returns `Result<(), Errno>` and `rw_assert_*` are empty without feature `diagnostic` | the C's `rw_cas` on the same word; `compare_exchange` on one CPU is the plain compare-and-store the `!MULTIPROCESSOR` build has |
| `vm_page_t *pps` arrays whose slots hold `NULL`, a page or the sentinel `PGO_DONTCARE` (`(struct vm_page *)-1`) (`pgo_get`, `uvm_fault`) | `&mut [*const VmPage]` with `PGO_DONTCARE` as `usize::MAX as *const VmPage` and `pgo_dontcare(p)`; functions that only read pages take `&[Option<&VmPage>]` (`uvm_page_unbusy`) | an `Option<&T>` has only "null" and "valid", so the sentinel needs the raw pointer; the pagers write the slots in place as the C does |
| a struct whose first member is the generic one and is cast both ways (`struct uvm_aobj { struct uvm_object u_obj; ... }`, `(struct uvm_aobj *)uobj`) | `#[repr(C)]` with the embedded struct first and one accessor that checks the C's type tag before casting (`fn aobj(&UvmObject) -> &UvmAobj` after `UVM_OBJ_IS_AOBJ`) | `repr(C)` pins the first field at offset 0, so the cast is the C's; the tag check is the only place the `unsafe` lives |
| unions of alternatives that are never read through the inactive member (`am_impl`, `u_swap`, `daddrs`, `dfree`, `object` in `vm_map_entry`) | side-by-side fields when both are small links (`am_small` beside the buckets, `addr_entry` and `addr_kentry`, `rbtree` and `dfree_tailq`); an `enum` when the C keeps a tag (`VmMapEntryObject` over `UVM_ET_OBJ`/`UVM_ET_SUBMAP`); a slice-or-pointer pair for `u_swap` | a Rust `union` needs `unsafe` on every read; the extra words cost less than the audit, and the enum makes the tag check the compiler's |
| a softc: `struct foo_softc { struct device sc_dev; ... }` allocated by `config_make_softc` as `malloc(ca_devsize, M_DEVBUF, M_NOWAIT\|M_ZERO)` and cast both ways (`(struct foo_softc *)self`) | `#[repr(C)] struct FooSoftc { sc_dev: Device, ... }` of `Cell`s (all-zero valid), marked `unsafe impl Softc`; `ca_devsize: size_of::<FooSoftc>()`; the driver gets `&Device` and calls `unsafe { self_.softc::<FooSoftc>() }` | the allocation and the cast are the C's: `repr(C)` puts the device at offset 0, `M_ZERO` makes the rest valid, and the `unsafe` names the one fact the compiler cannot see, which `cfattach` made the device |
| `void *aux` (a bus's attach arguments, read by the child as the bus's type) and `void *match` (a `cfdata`, or a softc below a `CD_INDIRECT` parent) | `aux: *mut c_void`, cast back with `&*aux.cast::<FdtAttachArgs>()` under a `// SAFETY:` naming the bus; `match` is `&CfMatch`, an enum of `Cfdata(&'static Cfdata)` and `Softc(SoftcMatch)` with `cfdata()` for either | the bus decides the type of `aux` at run time, as in C, so a raw pointer is honest; `match` has only two meanings and the tag (the parent's `CD_INDIRECT`) is known to autoconf, so an enum makes the cast unnecessary |
