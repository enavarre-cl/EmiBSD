# ports.toml

Source of truth for what is ported. `cargo xtask ports check` validates it; `just ci` runs that.

```toml
[meta]
upstream = "https://github.com/openbsd/src"
pinned   = "<full commit hash>"          # must equal the Commit: line in reference/PINNED.md

[[file]]
c      = "sys/lib/libkern/strlcpy.c"     # path inside reference/openbsd-src; one entry per C file
rust   = "sys/lib/libkern/strlcpy.rs"    # several C files may share one .rs; empty only when skipped
status = "ported"                         # todo | wip | ported | skipped
upstream_commit = "<full hash>"           # [meta].pinned at port time (wip, ported)
upstream_blob   = "<blob hash>"           # git -C reference/openbsd-src rev-parse HEAD:<c>  (ported)
deps   = ["sys/sys/types.h"]              # C paths that must be ported first (feeds `ports next`)
license = "none"                          # optional: the C file has no licence text (no <LICENSES> zone)
notes  = ""                               # REQUIRED when skipped: replaced-by-<x> | provided-by-core |
                                          # deferred-driver | license: <x> | not-applicable, then why

[[extra]]                                 # a Rust file under sys/ that is not the port of any C file
rust   = "sys/kern/unported.rs"
reason = "project helper: visible stubs for unported subsystems"
```

- Transitions: `todo → wip → ported`; `todo → skipped`. Never `ported → todo` without a commit
  message explaining the regression.
- Headers count as files (`sys/sys/queue.h` → `sys/sys/queue.rs`).
- Every `.rs` under `sys/` except `mod.rs`, `lib.rs`, `main.rs`, `build.rs`, `sys/machine/`,
  `sys/arch/host/` and `sys/stand/` must be referenced
  by a `[[file]]` or an `[[extra]]`.
- `deps` only reference C paths that have their own entry. A `skipped` dependency counts as satisfied.
- The table in `docs/PORTING.md` between the markers is generated by
  `cargo xtask ports status --write`. Never edit it by hand.
- Do not bulk-import thousands of C files as `todo`; add entries when a milestone claims them.
- Zone markers (M15): `cargo xtask ports check` validates `/* <LICENSES> */`, `/* <CODE> */` and
  `/* <TESTS> */` in every `.rs` under `sys/` and `tools/` (`rust-kernel.md`, file layout).
  `<LICENSES>` must be in a file that has a `[[file]]` entry with status `wip` or `ported`, unless
  the entry says `license = "none"` (a C file with no licence text, or a generated file; the
  `.S` ports whose notice stays in the `.S` beside the `.rs`), and may not be in any other
  file (`[[extra]]` or untracked). A `tests.rs` is an error.
